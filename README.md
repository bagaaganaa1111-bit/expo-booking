# Үзэсгэлэнгийн лангуу захиалгын систем

Ажилтан талбайн зургаа оруулахад систем лангуунуудыг автоматаар таньж, оролцогч байгууллагууд нэг холбоосоор сул лангуугаа сонгож захиална. Тусдаа сервер шаардлагагүй, үнэгүй хэрэгслүүд дээр ажиллана.

| Хэсэг | Хаана ажиллах | Файл |
|---|---|---|
| Өгөгдлийн сан | Google Sheets | (setup() автоматаар үүсгэнэ) |
| Сервер | Google Apps Script | `apps-script/Code.gs` |
| Оролцогчийн хуудас | GitHub Pages | `web/index.html` |
| Ажилтны хуудас | GitHub Pages | `web/admin.html` |
| Тохиргоо, загвар | GitHub Pages | `web/config.js`, `web/common.js`, `web/style.css` |

---

## 1. Google Sheets ба Apps Script (15 минут, нэг удаа)

1. Google Drive-д шинэ **Google Sheets** файл үүсгээд `Лангуу захиалга` гэж нэрлэнэ.
2. **Extensions → Apps Script** цэсийг нээнэ.
3. Нээгдсэн `Code.gs` доторх бүх кодыг устгаад, `apps-script/Code.gs` файлын агуулгыг хуулж тавина. **Save** дарна.
4. Зүүн талын ⚙️ **Project Settings** → доод хэсгийн **Script properties** → **Add script property**:

   | Нэр | Утга | Заавал эсэх |
   |---|---|---|
   | `ADMIN_PIN` | Захирлын нэвтрэх 6 оронтой PIN | Тийм |
   | `CLAUDE_API_KEY` | console.anthropic.com дээрээс авсан түлхүүр | Зураг автоматаар таниулах бол |
   | `TELEGRAM_TOKEN` | @BotFather-аас авсан ботын токен | Мэдэгдэл авах бол |
   | `TELEGRAM_CHAT` | Менежерүүдийн группын ID (захиалга, төлбөр, цуцлалт) | Мэдэгдэл авах бол |
   | `TELEGRAM_DIRECTOR` | Захирлуудын чатын ID (олон бол таслалаар): захиалга, төлбөр + өглөөний санхүүгийн тайлан + системийн алдаа, AI кредит, шинэчлэл, нөөц | Үгүй |
   | `TELEGRAM_ADMIN` | Систем админы хувийн чатын ID (системийн алдаа, AI кредит, шинэчлэл, нөөц) | Үгүй |
   | `CLAUDE_MODEL` | Хоосон орхивол `claude-sonnet-5-5` | Үгүй |

5. Кодын цонх руу буцаж, дээд талын функцийн жагсаалтаас **setup**-ийг сонгоод **Run** дарна. Анх удаа Google зөвшөөрөл асууна: *Review permissions → бүртгэлээ сонгох → Advanced → Go to … (unsafe) → Allow*. Энэ нь таны өөрийн скрипт учир аюулгүй.
   - Sheets дотор `Үзэсгэлэн`, `Салбар`, `Лангуу`, `Ажилтан`, `Түүх`, `Бүтээгдэхүүн`, `Оролцоо`, `Оролцогчид` хуудсууд үүснэ.
   - `Бүтээгдэхүүн` хуудсанд 8 үзэсгэлэнгийн загвар, 83 бүтээгдэхүүн анхнаасаа бичигдэнэ (хоосон үед л).
   - Цаг тутмын шалгалт (48 цаг) ба өглөө 9 цагийн тайлан автоматаар тохируулагдана.
6. Telegram тохируулсан бол **testTelegram**-ийг сонгоод **Run** дарна. Туршилтын мессеж ирэх ёстой.
7. **Deploy → New deployment** → ⚙️ → **Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
   - **Deploy** дараад гарсан **Web app URL**-ийг хуулж авна (`https://script.google.com/macros/s/…/exec`).

> Кодыг дараа нь өөрчилбөл **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** хийнэ. Ингэвэл холбоос өөрчлөгдөхгүй.

## 2. GitHub Pages (5 минут)

1. `web/config.js` файлыг нээж `PASTE_WEB_APP_URL_HERE`-ийн оронд дээрх Web app URL-ийг тавина.
2. GitHub дээр **нийтийн (public)** репо үүсгэж, `web/` хавтас доторх 5 файлыг репогийн үндсэн хэсэгт байршуулна.
3. Репо → **Settings → Pages** → *Branch*: **main**, */(root)* → **Save**. 1–2 минутын дараа холбоос гарна:
   - Ажилтан: `https://<нэр>.github.io/<репо>/admin.html`
   - Оролцогч: ажилтны хуудаснаас "Оролцогчийн холбоос хуулах" дарж авна (`…/?e=<үзэсгэлэнгийн код>`).

## 3. Эрх ба ажилтан нэмэх

| Эрх | Юу хийх |
|---|---|
| **Систем админ** | Бүх эрх + систем админыг удирдах; системийн алдааны мэдэгдэл авна |
| **Захирал** | Бүх ажил + үнэ, тохиргоо, захиалга нээх/хаах, санхүүгийн дүн, ажилтан удирдах |
| **Менежер** | Захиалга, төлбөр бүртгэх, цуцлах, лангуу засах. Үнэ, тохиргоо, санхүүгийн нийт дүн харагдахгүй |

Захирал эсвэл систем админ ажилтны хуудасны **Ажилтан** товчоор ажилтан нэмж, PIN олгож, эрхийг өөрчилж, идэвхгүй болгоно.

## 4. Telegram мэдэгдэл ба товчнууд

1. @BotFather → `/newbot` → токеныг `TELEGRAM_TOKEN`-д хадгална.
2. Захирлуудын групп үүсгэж ботыг нэмээд `/start` гэж бичнэ. Систем админ ботод хувиараа `/start` гэж бичнэ.
3. Чатын ID олох хамгийн амар арга: тухайн хүн ботод (эсвэл группт) **/id** гэж бичихэд бот ID-г хариулна. Эсвэл Apps Script дээр **telegramChats** функцийг ажиллуулахад чат бүрийн ID доор гарна. Группын ID-г `TELEGRAM_DIRECTOR`, өөрийнхөө ID-г `TELEGRAM_ADMIN`-д хадгална. (`TELEGRAM_CHAT` нь менежерийн групп байвал л.)
4. **testTelegram**-ийг ажиллуулж чат бүрт туршилтын мессеж очсоныг шалгана.
5. **tgConnect**-ийг нэг удаа ажиллуулна. Ингэснээр товчнууд идэвхжиж, группт цэс очно.

**Товчнууд:**
- Шинэ захиалгын мэдэгдлийн доор: **✅ Урьдчилгаа орсон**, **💵 Бүтэн төлсөн**, **⏳ 24 цаг сунгах**, **❌ Цуцлах** (цуцлахад дахин асууна). Хэн дарсан нь мессеж дээр болон Түүх хуудсанд бичигдэнэ.
- Цэс (мессеж доорх товч эсвэл бичих талбайн хажуугийн **Menu**): **📊 Өнөөдрийн байдал**, **💰 Авлага**, **⏰ Хугацаа дуусах**, **🔎 Хайх** (утас эсвэл байгууллагын нэрээр), **🗂 Оролцогчид** (шүүлттэй жагсаалт, доороос үзнэ үү).
- Бот зөвхөн тохируулсан чатуудаас ирсэн командыг хүлээн авна.
- Нэг товчийг хоёр хүн зэрэг дарвал эхнийх нь л бүртгэгдэж, нөгөөд нь "өөр хүн өөрчилсөн" гэж гарна.
- Товч идэвхтэй үед шинэ хүн нэмэх бол: тэр хүн ботод `/start` бичээд **telegramChats** ажиллуулахад ID нь гарна.

## 5. Бүтээгдэхүүн ба оролцогчдын сан

**Бүтээгдэхүүний жагсаалт (`Бүтээгдэхүүн` хуудас)** — захирал, менежер Sheets дээр шууд засна:
- Мөр бүр: Үзэсгэлэн (загварын нэр) · Дүрс · Бүтээгдэхүүн · Салбар · Идэвхтэй (Тийм/Үгүй).
- Шинэ мөр нэмэхэд "Үзэсгэлэн" баганад загварын нэрийг яг ижил бичнэ. Шинэ нэр бичвэл шинэ загвар болно.
- Хасах бол мөрийг устгахгүй, **Идэвхтэй = Үгүй** болгоно (хуучин захиалгын түүх хэвээр).
- Засвар захиалгын маягтад шууд (10 секундэд) орно.

**Үзэсгэлэн үүсгэхдээ** "Үзэсгэлэн (бүтээгдэхүүний жагсаалт)" талбараас загвараа сонгоно. Нэр, огноо, байршлыг өмнөх шигээ оруулна. Дараа нь тохиргооноос солиж болно. Загвар сонгосон бол оролцогч захиалахдаа **3 хүртэл бүтээгдэхүүн** заавал сонгоно (+ "Бусад" бичиж болно). Утсаар захиалга авахад сонгох нь заавал биш.

**Автомат бүртгэл** — хэн ч гараар оруулахгүй:
- `Оролцоо` — захиалга бүр нэг мөр: үзэсгэлэн, лангуу, байгууллага, утас, бүтээгдэхүүн, төлөв, дүн. Цуцлагдсан, хугацаа дууссан ч мөр нь үлдэж, төлөв нь шинэчлэгдэнэ. Үзэсгэлэн бүрээр харахдаа Sheets-ийн шүүлтүүрээр "Үзэсгэлэн" баганыг шүүнэ.
- `Оролцогчид` — байгууллага бүр нэг мөр (утасны дугаараар нэгтгэнэ): бүх бүтээгдэхүүн, **оролцсон үзэсгэлэнгүүд**, тоо.
- Шинэчлэлт хийсний дараа `setup`-ийг нэг удаа ажиллуулахад одоо байгаа захиалгууд сан руу автоматаар хуулагдана.

**Долоо хоног бүрийн нөөц:** Ням гараг бүр 22 цагт Оролцогчид, Оролцоо хуудсыг Drive дахь **"Оролцогчдын сан — нөөц"** файл руу огноотой нэрээр хуулна (жишээ нь "Оролцогчид 2026-11-01"). Сүүлийн 8 долоо хоногийнх үлдэнэ. Систем админд Telegram-аар мэдэгдэл, файлын холбоос очно. Шууд нөөцлөх бол Apps Script дээр **weeklyBackup**-ийг ажиллуулна. Алдагдсан өгөгдлийг сэргээх бол нөөц файлаас хүссэн огнооны хуудсыг хуулж авна.

**Ботоор хайх — 🗂 Оролцогчид:** Үзэсгэлэн → Бүтээгдэхүүн → Төлөв (📋 Идэвхтэй бүгд · ✅ Төлбөртэй · ⏳ Төлбөр дутуу · ❌ Цуцлагдсан) сонгоход жагсаалт гарна. Захиралд нийт дүн/үлдэгдэл харагдана, менежерт харагдахгүй. Цэсийн **📑 Бүртгэл (Sheets)** товч Оролцогчид хуудсыг, үр дүнгийн доорх **📑 Бүтэн жагсаалт** товч Оролцоо хуудсыг шууд нээнэ (Sheets файлд Share-ээр эрх авсан хүнд нээгдэнэ).

## 6. 📸 Screenshot-оор оролцогч бүртгэх (Telegram)

**Анх нэг удаа — ажилтан бүр:** ботын **хувийн чат** руу `/login PIN` гэж бичнэ (админ хуудасны PIN). PIN-тэй мессеж автоматаар устна. Ажилтныг админ хуудаснаас идэвхгүй болгоход ботын эрх нь хамт хаагдана. Гарах: `/logout`.
> Групп дотор Telegram ботод зураг харуулдаггүй тул зургийг **хувийн чат** руу явуулна.

**Ажлын урсгал:**
1. Facebook пэйжийн **"Танилцуулга / About"** хэсэг, нэрийн хуудас эсвэл вэбсайтын зургийг ботод явуулна. Нэг байгууллагын хэд хэдэн зургийг нэг дор (цомгоор) явуулж болно — нэг картад нэгтгэнэ.
2. Бот шууд "⏳ Уншиж байна…" гэж хариулаад 5–15 секундэд карт гаргана: нэр, утас, имэйл, хаяг, салбар, тохирох үзэсгэлэн.
3. Алдаатай бол **карт руу reply** хийгээд энгийнээр бичнэ: "утас 99112233 нэмэх", "нэр Номин ХХК", "салбар барилга".
4. **🏷 Салбар** — 9 салбараас 3 хүртэл сонгоно. **✅ Хадгалах** → Оролцогчид хуудсанд нэмэгдэнэ.
5. Утас (үндсэн, нэмэлт) эсвэл нэр нь санд байвал **⚠️ Санд бүртгэлтэй** гэж харуулна. **🔄 Мэдээллийг нэмэх** нь зөвхөн хоосон талбарыг нөхөж, шинэ утсыг "Нэмэлт утас"-нд нэмнэ — байгаа мэдээллийг дарахгүй.
6. Тэр байгууллага дараа нь захиалга хийвэл (аль ч утсаараа) **ижил мөрөнд** оролцсон үзэсгэлэн нь нэмэгдэнэ.

**Санг харах:** 🗂 Оролцогчид → **🏷 Бүх сан — салбараар** → салбар бүрийн байгууллагууд (🎪 = оролцсон үзэсгэлэнгийн тоо, "шинэ" = хараахан оролцоогүй).

**Тэмдэглэл:** хадгалаагүй ноорог 6 цагийн дараа устна. AI кредит дуусах, завгүй байх үед ажилтанд ойлгомжтой хариу, систем админд мэдэгдэл очно. Нэг зураг AI-д ойролцоогоор 1–3 цент зарцуулна.

## Ажилтан хэрхэн ашиглах вэ

1. **admin.html**-ийг утас эсвэл компьютерээс нээж PIN-ээр нэвтэрнэ.
2. **Шинэ үзэсгэлэн** — нэр, огноо оруулаад "Үүсгэх".
3. **Зураг сонгох** — талбайн зургийг оруулахад систем 1–2 минутад лангуунуудыг таньж гаргана.
4. **Шалгах** — зураг дээр хүрээ бүр лангуутайгаа таарч байгааг харна. Зөрсөн бол лангууг дарж сонгоод чирж зөөнө, буланд нь чирж хэмжээг тааруулна. Дутуу бол "+ Лангуу нэмэх".
5. **Салбар ба үнэ** — салбар бүрийн 1 м²-ийн үнийг оруулна → **Хадгалах**.
6. **Тохиргоо** — төлбөрийн данс, түр барих хугацаа (48 цаг), урьдчилгааны хувь.
7. **Захиалга нээх** → **Оролцогчийн холбоос хуулах** → Facebook, Viber, имэйлээр илгээнэ.
8. Захиалга орох бүрт Telegram-аар мэдэгдэл ирнэ. Төлбөр орсон бол лангууг дарж **Урьдчилгаа орсон** → **Үлдэгдэл орсон**.
9. Утсаар ярьж байгаа байгууллагад сул лангууг дарж **Утсаар захиалга авах**.

## Систем өөрөө юу хийдэг вэ

- Нэг лангууг хоёр байгууллага зэрэг захиалах боломжгүй.
- Нэг утасны дугаараар төлбөргүй 3-аас олон лангуу барих боломжгүй (хуурамч захиалгаас хамгаална).
- Урьдчилгаа заасан хугацаанд ороогүй түр захиалгыг автоматаар суллаж, Telegram-аар мэдэгдэнэ.
- Захиалсан үеийн үнэ түгжигдэнэ. Захиалгатай лангууг зөөх, устгах, зургийг солихыг хориглоно.
- Үнэгүй (м² эсвэл салбарын үнэ дутуу) лангуу байвал захиалга нээхийг зөвшөөрөхгүй.
- Өглөө бүр 9 цагт: захиалагдсан хувь, орсон төлбөр, авлага, 24 цагт барьцаа нь дуусах лангуунууд.
- Бүх өөрчлөлт **Түүх** хуудсанд хэн, хэзээ хийснээрээ бүртгэгдэнэ.
- Системийн алдаа гарвал Telegram-аар анхааруулга ирнэ.

## Шинэчлэл суулгах (бүтээгдэхүүн, оролцогчдын сан)

1. `apps-script/Code.gs`-ийг Apps Script руу бүтнээр нь хуулж тавиад **Save**.
2. **setup**-ийг нэг удаа **Run** — шинэ хуудсууд үүсэж, бүтээгдэхүүн бичигдэж, одоогийн захиалгууд сан руу хуулагдана. Өмнөх өгөгдөлд хүрэхгүй.
   Мөн долоо хоног бүрийн нөөцийн хуваарь тохируулагдана. Эхний нөөцийг шууд үүсгэх бол **weeklyBackup**-ийг нэг удаа ажиллуулна (Drive руу хандах зөвшөөрөл дахин асууж магадгүй).
3. **Deploy → Manage deployments → ✏️ → New version → Deploy**.
4. **tgConnect**-ийг нэг удаа ажиллуулна (ботын цэсэнд 🗂 Оролцогчид нэмэгдэнэ).
5. Ажилтнууд ботын хувийн чатад `/login PIN` гэж бичиж холбогдоно.

## 🚀 Автомат deploy (GitHub → Apps Script)

Тохируулсны дараа `apps-script/Code.gs` өөрчлөгдөж `main` руу push хийгдэхэд **1–2 минутад** Apps Script өөрөө шинэчлэгдэнэ: код хуулах, setup, New version, tgConnect — алийг нь ч гараар хийхгүй.

**Яаж ажилладаг вэ** (`.github/workflows/deploy-apps-script.yml` → `tools/deploy-gas.mjs`):
1. Синтакс шалгана. Алдаатай бол deploy хийхгүй.
2. Одоогийн кодыг нөөцлөнө (GitHub Actions → artifact, 90 хоног).
3. Зөвхөн **Code** файлыг солино — manifest, бусад файл хэвээр.
4. Шинэ хувилбар үүсгэж веб аппыг түүн рүү шилжүүлнэ (**холбоос өөрчлөгдөхгүй**).
5. Веб аппыг 3 удаа шалгана. Ажиллахгүй бол **өмнөх хувилбар руу автоматаар буцаана**, GitHub танд имэйлээр мэдэгдэнэ.
6. Шинэ хувилбарын анхны хүсэлт дээр систем өөрөө шилжилт хийнэ (шинэ хуудас/багана, бүтээгдэхүүн, хуваарь, ботын цэс) — `setup` гараар ажиллуулах хэрэггүй. Систем админд **"🔄 Систем шинэчлэгдлээ"** мессеж очно.

**Нэг удаагийн тохиргоо (≈10 минут):**
1. **Apps Script API асаах:** https://script.google.com/home/usersettings → *Google Apps Script API* → **ON**.
2. **Script ID:** Apps Script → ⚙️ *Project Settings* → *IDs* → **Script ID**-г хуулна.
3. **Google нэвтрэлт (clasp login)** — аль нэгээр нь:
   - *Компьютер дээр:* nodejs.org-оос Node.js (LTS) суулгаад PowerShell дээр `npx @google/clasp login` → нээгдсэн хөтөч дээр **скрипт эзэмшдэг Google бүртгэлээ** сонгоод *Allow* → `notepad $HOME\.clasprc.json` → агуулгыг бүтнээр нь хуулна.
   - *VPS дээр:* `docker run --rm -it node:22 sh -c "npx -y @google/clasp login --no-localhost && cat /root/.clasprc.json"` → заасан холбоосыг хөтөчөөр нээж зөвшөөрөөд гарсан кодыг буулгана → хэвлэгдсэн JSON-ийг хуулна.
4. **GitHub secret:** репо → *Settings → Secrets and variables → Actions → New repository secret*:
   - `CLASPRC_JSON` = 3-р алхмын JSON (бүтнээр)
   - `SCRIPT_ID` = 2-р алхмын Script ID
5. **Шалгах:** репо → *Actions → Apps Script deploy → Run workflow*. Ногоон ✓ гарч, Telegram-д "🔄 Систем шинэчлэгдлээ" ирвэл бэлэн.

**Анхаарах:**
- Apps Script доторх кодын файл **Code** нэртэй байх ёстой (анхдагч нэр).
- `CLASPRC_JSON` нь таны Google бүртгэлийн Apps Script-д хандах түлхүүр — хэнд ч бүү үзүүл; GitHub secret нийтийн репод ч нууц хадгалагдана. Нууц алдагдсан гэж үзвэл https://myaccount.google.com/permissions дээр "clasp"-ийн эрхийг хасаад 3–4-р алхмыг давтана.
- Код шинэ төрлийн Google эрх (жишээ нь Gmail) шаардвал Apps Script дээр аль нэг функцийг нэг удаа гараар ажиллуулж зөвшөөрөл өгнө. Ийм өөрчлөлт хийх үед урьдчилан хэлнэ.
- "Нэвтрэлт хүчингүй" алдаа гарвал (Google нууц үг сольсон гэх мэт) 3–4-р алхмыг давтана.

## Шинэ хувилбар алдаатай бол буцаах (1 минут)

Apps Script → **Deploy → Manage deployments** → ✏️ → **Version** жагсаалтаас өмнөх хувилбарыг сонгоод **Deploy**. Холбоос өөрчлөгдөхгүй, систем шууд хуучин хувилбараараа ажиллана.

## Хамгаалалт

- Хүснэгтүүд хамгаалагдсан: эзэмшигчээс бусад хүн гараар засах боломжгүй. Систем хэвийн бичнэ.
- PIN 10 удаа буруу оруулбал ажилтны нэвтрэлт 15 минут хаагдаж, систем админд мэдэгдэнэ.
- Нийтийн хуудасны мэдээлэл 10 секунд кэшлэгдэнэ: олон хүн зэрэг ороход сервер ачааллахгүй.
- Цаг тутмын шалгалт, өглөөний тайлан алдаа гарвал систем админд мэдэгдэнэ.

| Шинж тэмдэг | Шалгах зүйл |
